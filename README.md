# OLS Profile Switcher

A simple VS Code extension to switch Odin Language Server profiles directly from the status bar.

## Features

- Detects ols.json in your workspace.
- Reads available profiles from the profiles array.
- Displays the active profile in the VS Code status bar.
- Click the status bar item to select another profile.
- Updates ols.json when switching.
- Watches for external changes to ols.json.
